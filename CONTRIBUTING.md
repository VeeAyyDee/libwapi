# Contributions

Bug reports, reproductions, tests and patches are welcome. Submit changes to
this library under MPL-2.0 and retain third-party notices. Do not include vendor
binary code, decompiler output, credentials or device backups in submissions.

Please describe the SDK version, board, observed failure, and tests performed.
Keep ABI-sensitive changes explicit and preserve the original-source provenance.
Sending fixes upstream is encouraged; MPL itself requires source availability
to recipients when covered software is distributed, not submission to this repo.
